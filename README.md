# LogicLab 邏輯閘練習

給「數位邏輯設計」課程使用的線上邏輯閘練習網頁。學生可以在瀏覽器裡拖曳邏輯閘、連線、即時模擬，自動產生真值表、布林表示式與時序圖，完成練習題並繳交作業；老師可以產生作業連結、一次批改全班作業並下載成績。

整個網站是**純前端靜態網頁**（HTML／CSS／JavaScript），不需要伺服器、資料庫或登入，放到 GitHub Pages 就能使用，也可以直接在電腦上雙擊 `index.html` 開啟。

## 功能一覽

**學生**
- 元件：輸入開關、輸出指示燈、常數 0／1、NOT、BUF、AND、OR、NAND、NOR、XOR、XNOR（多輸入閘可設 2～4 個輸入）、文字註解
- 拖曳放置、拖曳連線（或點兩個接腳連線）、移動、框選、複製貼上、復原／重做、縮放與平移
- 即時模擬：導線橘色＝1、深灰＝0、虛線＝不確定（有輸入端沒接線）；偵測迴路
- 真值表（點任一列即可切換輸入）、由電路寫出的布林表示式（A'B + C 記法）、最小項 Σm
- 時序圖：可自訂輸入波形，按「播放」讓電路隨時間變化
- 18 題內建練習（第 4 週：認識邏輯閘、NAND／NOR 萬用閘、由布林式畫電路、組合電路設計、挑戰題），可自動檢查答案並指出錯誤的列
- 傳統（ANSI／IEEE）或矩形（IEC）符號、直角或曲線導線、深色模式
- 作答自動儲存在瀏覽器；可下載電路檔換電腦繼續做
- 下載電路圖 PNG（含真值表），或直接複製圖片貼到簡報

**老師**（右上角「教師專區」）
- **出題**：輸入布林式或最小項（也可以直接用畫布上的電路當答案），設定可用的閘、閘數上限等限制，產生**作業連結**
- **批改**：拖入學生的作業檔（可多個）或 Google 表單回覆 CSV，系統重新模擬每個電路並比對真值表與限制，可下載成績 CSV
- 提示可能的問題：檔案被修改過、版面與其他同學完全相同、作答題目版本不同

## 先在自己的電腦試用

解壓縮後，直接雙擊 `index.html`，用 Chrome 或 Edge 開啟即可。

> 本機開啟時所有功能都能用；但「作業連結」要等部署到網站後，在網站上產生的連結學生才能開。

## 部署到 GitHub Pages

### 方法一：用網頁上傳（不需要安裝 git）

1. 登入 GitHub，按右上角 **+** → **New repository**。
2. Repository name 輸入例如 `logiclab`，選 **Public**，按 **Create repository**。
   （GitHub 免費帳號的 Pages 只能用在 Public repository。）
3. 在新 repository 頁面點 **uploading an existing file**，把這個資料夾裡的**所有檔案與 `src` 資料夾**拖進去，按 **Commit changes**。
   `index.html` 必須在 repository 的最上層。
4. 到 **Settings** → 左側 **Pages** → **Build and deployment** 的 **Source** 選 **Deploy from a branch**，
   Branch 選 **main**、資料夾選 **/ (root)**，按 **Save**。
5. 等 1～2 分鐘，網址會顯示在同一頁，格式為：
   `https://你的帳號.github.io/logiclab/`

### 方法二：用 git 指令

```bash
cd logiclab
git init
git add .
git commit -m "LogicLab 邏輯閘練習"
git branch -M main
git remote add origin https://github.com/你的帳號/logiclab.git
git push -u origin main
```

推上去之後，一樣到 **Settings → Pages** 設定 **Deploy from a branch → main → / (root)**。
之後修改檔案再 push，網站會自動更新。

## 課堂與作業的建議流程

1. **課堂練習**：學生打開網址，從上方「題目」選單選練習題，完成後按「檢查答案」。
   也可以直接給題目連結，例如 `https://你的帳號.github.io/logiclab/#ex=w4-13`（半加器）。
2. **指定作業**：教師專區 → 出題 → 填好題目 → **產生作業連結**，把連結貼到教學平台。
   學生打開連結就會載入這份作業，輸入輸出也已經放好（名稱固定，方便批改）。
3. **學生繳交**（右側「繳交」分頁，輸入學號與姓名），三選一：
   - **下載作業檔**（`學號_題目代號.json`）→ 上傳到教學平台
   - **複製繳交代碼** → 貼到 Google 表單
   - **下載電路圖（PNG）** → 上傳圖片（只能人工批改）
4. **批改**：教師專區 → 批改作業 → 把收到的 `.json` 檔全部拖進去（或 Google 表單的回覆 CSV）→ 檢視結果 → **下載成績（CSV）**。
   若要嚴格以某份作業為準，把該作業連結貼到「批改依據」欄位。

### 用 Google 表單收作業

1. 建立表單，新增三題：「學號」（簡答）、「姓名」（簡答）、「繳交代碼」（**段落**）。
2. 學生在 LogicLab 按「複製繳交代碼」，貼到「繳交代碼」欄。
3. 表單的「回覆」→ 下載回覆（.csv）→ 拖進 LogicLab 的「批改作業」，系統會自動找出每一列的代碼並批改。

## 新增或修改內建題目

內建題目都在 `exercises.js`，用任何文字編輯器打開就能修改，存檔後重新上傳（或 push）即可。每一題的格式：

```js
{
  id: 'w5-01',                      // 題目代號（不可重複）
  group: '第 5 週｜布林代數',         // 題目選單中的分組
  level: 2,                         // 1 入門、2 基礎、3 進階、4 挑戰
  title: '化簡後實現電路',
  desc: '<p>請實現 <code>F = AB + AB\'C</code>，並盡量減少閘的數量。</p>',
  inputs: ['A', 'B', 'C'],          // 第一個是真值表的最高位元
  outputs: { F: "AB + AB'C" },      // 也可以寫 "m(1, 3, 5)" 或 "m(1, 2) + d(3)"
  allowed: ['AND', 'OR', 'NOT'],    // （選填）只能使用的閘
  maxGates: 2,                      // （選填）閘數上限
  maxFanIn: 2,                      // （選填）每個閘最多幾個輸入
  showTarget: false,                // （選填）題目頁直接顯示目標真值表
  selfCheck: true,                  // （選填）false = 學生不能自己檢查
  hint: '先化簡：AB + AB\'C = A(B + C)'
},
```

布林式的寫法：反相用 `A'`（或 `!A`、`~A`），AND 可以相鄰寫 `AB` 或寫 `A·B`、`A*B`，OR 用 `+`，XOR 用 `⊕` 或 `^`，也可以加括號。多個字母的變數（例如 `Cin`）請列在 `inputs` 裡。

小技巧：在「教師專區 → 出題」設定好題目後，按「**複製為 exercises.js 題目**」就會產生可以直接貼上的程式碼。題目有錯誤時，教師專區會顯示錯誤訊息。

## 檔案說明

| 檔案 | 說明 |
|---|---|
| `index.html` | 網頁本體 |
| `style.css` | 版面與配色 |
| `app.js` | 程式（由 `src/` 合併產生，請不要直接修改） |

## 常見問題

**學生的作答存在哪裡？**
存在學生自己瀏覽器的 localStorage（同一台電腦、同一個瀏覽器才看得到）。換電腦請用「檔案 → 儲存電路檔」，到新電腦再「開啟檔案」。清除瀏覽器資料會刪掉作答。

**會收集學生資料嗎？**
不會。網站沒有伺服器，也不會把任何資料傳出去；學號姓名只存在學生的瀏覽器，以及他們自己下載或複製的作業檔／代碼裡。

**批改結果可以信任嗎？**
批改時一律**重新模擬學生的電路**，不採用檔案內學生自己的檢查結果；內建題目以網站上目前的題目定義為準。檔案被手動修改、兩位同學版面完全相同時會提示，但這只是參考，並不是防作弊系統。

**支援哪些瀏覽器？**
新版 Chrome、Edge、Firefox、Safari 都可以（包含平板與手機；電腦操作最順手）。

**網址後面的 `#hw=…` 很長，正常嗎？**
正常。作業內容（題目、目標真值表、限制）都壓縮在連結裡，所以不需要伺服器。
